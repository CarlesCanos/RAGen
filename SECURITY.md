# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/CarlesCanos/RAGen/security/advisories/new).
Do not publish sensitive details in an issue, discussion, or pull request.

Include a clear description, reproduction steps, affected versions, and the likely
impact. Remove personal documents, local paths, credentials, and tokens from every
example or log.

If private reporting is unavailable, open a public issue asking the maintainer for a
private contact channel without describing the vulnerability.
